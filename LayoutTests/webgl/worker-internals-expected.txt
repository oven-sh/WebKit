Tests that dedicated and shared workers have the internals object with the WebGL functions when their script starts.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


Dedicated worker
PASS state.internals is "object"
PASS state.settings is "undefined"
PASS state.simulateEventForWebGLContext is "function"
PASS state.webglMaxDrawingBufferSize is "function"
PASS state.requestedGPU is "function"
PASS state.webglMaxDrawingBufferSizeResult is "valid"
PASS state.requestedGPUResult is "default"

Shared worker
PASS state.internals is "object"
PASS state.settings is "undefined"
PASS state.simulateEventForWebGLContext is "function"
PASS state.webglMaxDrawingBufferSize is "function"
PASS state.requestedGPU is "function"
PASS successfullyParsed is true

TEST COMPLETE

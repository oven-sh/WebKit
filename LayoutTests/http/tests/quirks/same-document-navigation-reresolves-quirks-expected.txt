Tests that site-specific quirks are re-resolved when history.pushState() or history.replaceState() changes the top document URL, in the top document and in its subframes. apple.com has a quirk for paths containing /retail.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


Initial URL:
PASS topDocumentHasQuirk() is false
PASS subframeHasQuirk() is false

history.pushState() to /retail:
PASS topDocumentHasQuirk() is true
PASS subframeHasQuirk() is true

history.replaceState() to /:
PASS topDocumentHasQuirk() is false
PASS subframeHasQuirk() is false

history.replaceState() to /retail/store:
PASS topDocumentHasQuirk() is true
PASS subframeHasQuirk() is true
PASS successfullyParsed is true

TEST COMPLETE
